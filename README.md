# 🌿 SmartGrowController

> Professional ESP32 Smart Grow Controller

An open-source smart grow controller designed for indoor gardens, cannabis cultivation, hydroponics, and automated plant care.

---

## Features

- 🌡 Temperature Monitoring
- 💧 Humidity Monitoring
- 🌱 Soil Moisture Monitoring
- 🚰 Reservoir Water Level Monitoring
- ☀ Light Level Monitoring
- 💦 Automatic Watering
- 🔔 Audible Alerts
- 📺 I2C LCD Display
- 🌐 Wi-Fi Dashboard *(Coming Soon)*
- 📱 Mobile Friendly Interface *(Coming Soon)*
- 📈 Historical Charts *(Planned)*
- 🔄 OTA Firmware Updates *(Planned)*
